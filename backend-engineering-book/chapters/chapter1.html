1.1 What is Backend?

Backend is the part of an application that works behind the scenes. It receives requests from users, processes data, communicates with the database, performs business logic and finally sends a response back to the client.

📌 Definition

Backend = Server + Business Logic + Database + APIs.

1.2 Frontend vs Backend

Frontend Backend
User Interface Business Logic
HTML CSS JavaScript Node.js Express
Runs in Browser Runs on Server
Visible to User Hidden from User
Calls APIs Creates APIs

1.3 Real Life Example

Imagine Swiggy.

  • User opens App.
  • Selects Food.
  • Clicks Order.
  • Frontend sends API request.
  • Backend verifies user.
  • Backend checks restaurant.
  • Backend calculates bill.
  • Backend stores order in database.
  • Backend returns success response.

💡 Remember

User never directly talks to the database. Everything goes through Backend.

  • ❌ Thinking Backend = Database only.
  • ❌ Putting all code in one file.
  • ❌ Not validating user input.
  • ❌ Saving plain passwords.
  • ❌ Hardcoding secrets.
  • ❌ Returning sensitive data.

1.10 Interview Questions

Q. What is Backend?

Backend is the server-side of an application responsible for handling business logic, authentication, APIs and database operations.

Q. Difference between Frontend and Backend?

Frontend focuses on UI while Backend manages data, logic and server-side operations.

Q. Can a website work without Backend?

Yes, if it is a static website. Dynamic applications require a backend.
