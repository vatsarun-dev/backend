3.1 Introduction to Node.js

Node.js is a JavaScript runtime environment that allows us to run JavaScript code outside the browser. Before Node.js, JavaScript could only run inside web browsers like Chrome, Firefox, and Edge. Node.js made it possible to build backend applications using JavaScript.

📌 Definition

Node.js is a JavaScript runtime built on Google's V8 JavaScript Engine that allows developers to build fast and scalable server-side applications.

3.1.1 Why Do We Need Node.js?

Earlier, JavaScript was only used for frontend development. If you wanted to build a backend, you had to learn another language like Java, PHP, Python, or C#. Node.js solved this problem by allowing developers to use JavaScript for both frontend and backend. 



Before Node.js

Frontend  → JavaScript

Backend   → Java / PHP / Python





After Node.js

Frontend  → JavaScript

Backend   → JavaScript

3.1.2 Where is Node.js Used?

Node.js is commonly used for building:

  • REST APIs
  • Backend Servers
  • Real-time Chat Applications
  • Authentication Systems
  • Streaming Applications
  • Microservices
  • Real-time Dashboards

3.1.9 Interview Questions

Q. What is Node.js?

Node.js is a JavaScript runtime environment built on Google's V8 Engine that allows JavaScript to run outside the browser.

Q. Is Node.js a programming language?

No. JavaScript is the programming language, and Node.js is the runtime environment that executes JavaScript outside the browser.

Q. What is the difference between Node.js and Express.js?

Node.js is the runtime environment, while Express.js is a web framework built on top of Node.js for creating servers and APIs.

Q. Can Node.js access files and databases?

Yes. Unlike browser JavaScript, Node.js can read/write files and connect to databases like MongoDB or MySQL.

3.2 How Node.js Works

Node.js is fast because it combines the V8 Engine, the Node.js Runtime, the Event Loop, and Non-Blocking I/O. Together, these components allow Node.js to handle thousands of requests efficiently.

📌 Key Idea

Node.js uses a single thread with an Event Loop to efficiently handle asynchronous operations without blocking other requests.

3.2.1 V8 JavaScript Engine

The V8 Engine is Google's JavaScript engine used in Chrome. Node.js uses this engine to execute JavaScript code.

Instead of interpreting JavaScript line by line, V8 compiles it into machine code, making execution much faster.

💡 Remember

Node.js is not the V8 Engine.
Node.js uses the V8 Engine internally.

3.2.2 What is Node.js Runtime?

The V8 Engine can only execute JavaScript. Node.js adds extra features that JavaScript alone doesn't have.

The Node.js Runtime provides APIs for:

  • Reading and Writing Files
  • Creating HTTP Servers
  • Working with Operating System
  • Networking
  • Timers

3.2.10 Interview Questions

Q. Why is Node.js fast?

Because it uses the V8 Engine, Event Loop, and Non-Blocking I/O to efficiently handle many requests.

Q. What is the V8 Engine?

The V8 Engine is Google's JavaScript engine that compiles JavaScript into machine code for faster execution.

Q. What is the Event Loop?

The Event Loop continuously checks for completed asynchronous tasks and executes their callbacks.

Q. What is Non-Blocking I/O?

Non-Blocking I/O allows Node.js to continue executing other tasks while waiting for I/O operations like file reading or database queries.

Q. Does Node.js use multiple threads to execute JavaScript?

No. JavaScript execution runs on a single main thread. Some background operations are handled outside the main thread, and their results are processed through the Event Loop.
